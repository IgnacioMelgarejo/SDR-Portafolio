# Ignacio Melgarejo — Business Portfolio

Portfolio profesional minimalista orientado a Business Operations, Revenue Operations, Sales Operations, Business Analytics y Account Management técnico.

## Stack
- HTML5
- CSS3
- JavaScript vanilla
- Sin dependencias de runtime

## Ejecutar localmente
```bash
python3 -m http.server 8000
```
Luego abrir `http://localhost:8000`.

## Deploy
Sitio estático listo para Vercel. Incluye `vercel.json`.

## Nota sobre los casos
Los dashboards y business cases utilizan datos simulados y no contienen información confidencial de empleadores anteriores.
